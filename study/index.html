One-page orientation

  1. Repo shape is gated. gates/repo.ts: every tracked file matches an allow line and stays under a ttok token cap. Growing past a cap fails the build.
  2. Tests are specimens. 1,302 files under tests/<ns>/; each ends in the exact lines its run must print; a pass needs four lanes (check · interpret · JS · C) to all agree.
  3. Numbers are measured, never typed. gen_pins.ts: "writes nothing it did not measure in the same run".
  4. Agents build, humans check the core. bend.ts (the checker) is hand-written; the rest is built for delegation under the gates.
  5. Refactoring is the standing price of the caps — compression is policy, not taste.
