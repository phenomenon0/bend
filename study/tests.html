Test doctrine — self-contained specimens

Every test is a Bend file that ends in the #| lines its run must print. No external harness, no fixtures outside the file: the expected output lives at the bottom of the file being tested, whole-lines byte-exact — including the compiler's error text and exit 1 for tests that must fail.

Specimen 1 — a value test

# a Char past ASCII shows as its quoted literal, one code point
import Base

law main:
  Char

def main():
  Chr{233}

#|'é'

Specimen 2 — a negative test (the error IS the output)

# bend3's slab bounds laws (total over u32 keys, defaults at unwritten
# slots); bend's Array<T> is a 2^d tree with wrapping bit-walk
# indexing and no literal -- the slab literal's spelling is the
# refusal (the in-range reads are covered by the ported array tests)
import Base

law main:
  U32

def main():
  m : [:U32] = ![0:10, 1:20, 3:7, _:0; 4]
  m[0]

#|Error:
#|- expected : 'def', 'type' or 'law'
#|- observed : ':'
#|Location:
#|10 | def main():
#|11>|   m : [:U32] = ![0:10, 1:20, 3:7, _:0; 4]
#|12 |   m[0]
#|exit 1

Specimen 3 — arithmetic with a helper law pair and a printed result

# wrap-around arithmetic chains: xorshift32, a modular-inverse round trip,
# a 31x hash chain and a wrapped fibonacci loop all land on pinned words
# ported from bend3: shift counts become Nat (U32.shln/shrn), loop
# counters become Nat, shared words become +U32 binders
import Base

law bu:
  for b: Bool
  U32

def bu(b):
  match b:
    case False{}:
      0
    case True{}:
      1

law xorshift:
  for +x: U32
  U32

def xorshift(x):
  +a = {U32.xor(x, U32.shln(x, 13n)) : U32}
  +b = {U32.xor(a, U32.shrn(a, 17n)) : U32}
  U32.xor(b, U32.shln(b, 5n))

law hash_go:
  for  n: Nat
  for +i: U32
  for  h: U32
… (expected output at the end: `#|4`)

Rules, observed across all 1,302

  • law/def pairs. A law declares the type first; the def body is checked against it. main gets its own law main:.
  • Four lanes (check · interpret via --checkup · JS via bun · C via clang -O3): all must print the #| lines; lane drops are explicit and conditional (no IO → not runnable; foreign def without the lane's twin → that lane drops).
  • Provenance headers. "ported from bend3:" style comments say where a test came from and what changed on the way.
  • Namespaces are the taxonomy — run, reg, spec, proof, state, show, parse, io, import, stuck, stats, cost, grade, gfx, … (dirs under tests/), numbered variants (_000, _001).
  • ≤ 16,000 ttok per test. If it grows bigger than that, it is cut up or cut down.
